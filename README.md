# Transportation Emissions Explorer

Interactive state-level exploration of U.S. road travel, highway fuel use, and transportation-energy indicators for 2000–2024.

Created by **Pouyan Hatami**.

## Current views
- Compare up to six states over time
- VMT per resident
- Highway fuel per 1,000 VMT
- Highway fuel per resident
- FHWA/EIA gasoline consistency ratio
- Interactive U.S. state map
- VMT vs. fuel-intensity quadrant explorer

## Data sources
- FHWA MF-21: highway motor-fuel use
- FHWA VM-2: vehicle miles traveled
- FHWA MF-225 / MF-226: historical backup fills where needed
- EIA SEDS: transportation motor gasoline and population

The site is a working research dashboard. Additional urban/rural travel and transportation CO2 views will be added as the analysis develops.
